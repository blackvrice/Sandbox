# v0.8 — Marketplace & Hosting

> **문서 상태:** 설계 초안 v0.1 | **기준일:** 2026-10-13 | **대상:** Sandbox C++23 기반 게임 제작·배포 플랫폼
> **범례:** [현행] GitHub `blackvrice/Sandbox`에서 확인한 구현, [신규] 새로 설계·구현할 기능, [결정 필요] 제품 정책 확정 전

## 1. 목표와 범위
**핵심 목표:** 경제활동과 유료 상시 서버 실험.

Sprite/패키지/게임 판매 및 공식 Persistent Hosting을 안전하게 운영한다.

**버전 정책:** 요금·수수료 정책은 제안 범위를 기반으로 시험하고 실제 PSP/세무·법률 검토 후 확정한다.

## 2. 진입 조건
이전 버전의 모든 필수 완료 기준 충족 및 릴리스 후보 통합 테스트

## 3. 구현 요구사항

1. 스토어 Listing, 가격/환불/Entitlement/License/Download

2. 결제 대행/웹훅 서명·멱등성/청구/정산 Ledger

3. 판매자 등록·콘텐츠 저작권 신고/분쟁·운영 콘솔

4. 유료 싱글플레이 게임 설치/업데이트와 에셋 배포

5. Persistent Hosting: 결제 상태 연동, 월드 저장·백업·복원

6. 서버 자원별 구독 티어, 사용량·원가 계측

7. 공식 호스팅 장애·비용·보안·개인정보 관리 정책

## 4. 아키텍처/데이터 영향

- 모듈 사이 역할·권한·데이터 소유자를 문서화하며, 기존 서버 권위 ECS·결정론·비동기 경계 원칙을 우선한다.

- Manifest·Script SDK·Network·Save의 변경사항은 호환 버전/Schema Migration 계약으로 관리한다.

## 5. 자동화 완료 기준

- [ ] 테스트 거래 → 자산 사용권 → 다운로드 → 환불/재정산

- [ ] 중복 PSP 웹훅·결제 실패·정산 보류 안전성

- [ ] 24h 서버 실행·강제 재시작·월드 복구·구독 만료 검증

- [ ] 게임 개발자와 에셋 판매자 별 정책 문서 완성

## 6. 데모 및 검증 시나리오

최소 1개의 재현 가능한 데모 프로젝트와 CI/CTest 실행 명령, 실패 시 기대 오류를 릴리스 문서에 포함한다. Marketplace & Hosting 기능을 외부 사용자가 처음부터 재현할 수 있어야 한다.

## 7. 위험·보류 항목

- 결제/정산/세무·소비자보호 법규가 국가별 상이

- 저작권 침해·차지백·무료 서버 운영비

- 새 API 및 사용자 흐름 문서화, 마이그레이션/롤백 검증 완료.
