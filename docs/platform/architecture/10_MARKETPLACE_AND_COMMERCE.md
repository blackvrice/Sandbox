# 11. Marketplace / 유료 게임 / 결제·정산 설계

> **문서 상태:** 설계 초안 v0.1 | **기준일:** 2026-10-13 | **대상:** Sandbox C++23 기반 게임 제작·배포 플랫폼
> **범례:** [현행] GitHub `blackvrice/Sandbox`에서 확인한 구현, [신규] 새로 설계·구현할 기능, [결정 필요] 제품 정책 확정 전

## 1. 사업 범위
- 에셋: Sprite/Texture/3D/음원/UI/Prefab/Feature/Script Package.
- 게임: 무료 게임, 유료 싱글플레이, 멀티플레이 게임 이용권.
- 호스팅: 상시 서버 구독 / 추가 저장·백업 / 네트워크 옵션.
- 비즈니스: 고급 협업·클라우드 빌드·거버넌스 구독.

## 2. 거래 도메인
```text
Listing → Price/Tax Quote → Checkout → Payment Provider
→ Order Confirmed → License/Entitlement Granted
→ Download / Package Install → Refund / Revocation Policy
→ Seller Settlement (after holds and adjustments)
```
- 주문·결제·인보이스·세금·라이선스·정산은 별도 데이터 모델.
- 구매자는 계정에 Entitlement를 얻고, 개발자는 명시적인 사용 허가를 받는다.
- 에셋 판매자는 일반적으로 저작권 소유자로 남고 라이선스 범위를 지정한다.

## 3. 수익 항목과 시험 가설
| 항목 | 요금 정책 | 원가·리스크 |
| --- | --- | --- |
| 게임 서버 | 월 구독(예약 자원/기간) | CPU, 네트워크, 저장·백업, 지원 |
| 에셋 판매 | 거래액에 대한 플랫폼 수수료(초기 10~15% 실험) | 결제·환불·저작권 분쟁 |
| 유료 게임 | 거래 수수료(초기 5~10% 실험) | 결제·세금·개발자 정산·스토어 유입 |
| Pro/Business | 월·연 또는 좌석당 구독 | CI 시간·저장·지원·보안 운영 |
이 비율은 시장 확정값이 아닌 가설. 결제 대행 수수료·VAT·환불·차지백·환율·정산 비용을 차감한 기여이익으로 검증한다.

## 4. 저작권 및 라이선스
- **공개 소스 != 오픈소스**. 소스 라이선스와 상업용 에셋 라이선스를 별도 관리.
- 게임 패키지에 통합된 유료 에셋의 재배포 가능 범위를 명시한다(예: 게임 내 번들 허용, 원본 추출/재판매 금지).
- 판매자 본인 확인(적용 법령/PSP 요구 범위), 저작권 신고·이의 제기·삭제·정산 보류 절차.
- 이미지/음원/코드의 AI 생성 여부를 표시할 정책은 법률·시장 변화에 맞춰 별도 결정.

## 5. 무료 이용자 정책
- 게임 제작/공개/개인 비공개 Repo 무료.
- 공개·비밀 코드 방 목록 및 Self-Hosting 등록 무료.
- 무료 세션은 남용 방지를 위한 할당량 표시.
- 유료 구독 없이도 자신의 게임·저장 데이터를 내보내는 권리 보장.

## 6. 환불과 보안
- 구매·사용권·서버 구독을 개별 환불 정책으로 관리.
- PSP 웹훅은 서명 확인·중복 처리 방지, 결제 상태와 Entitlement를 분산 트랜잭션/보상 흐름으로 연결.
- 원본 카드 정보를 직접 저장하지 않고 PSP의 보안 결제 흐름을 사용.
- 유료 게임·서버 이용권 권한은 서버에서 검증하되 오프라인 플레이 라이선스 정책도 마련.

## 7. 완료 기준
테스트 결제/실패/중복 콜백/환불/정산 실패/라이선스 회수·유지 정책을 자동 검증. 상점 출시 전 실제 세금·소비자보호·저작권 법률 검토 필요.
