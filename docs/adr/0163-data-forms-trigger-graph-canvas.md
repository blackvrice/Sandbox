# ADR-0163. 데이터 폼 (컴포넌트 리플렉션 → Prefab 폼) · 트리거 그래프 캔버스 (pos · 끌어 잇기)

- 상태: **Accepted** · 날짜: 2026-11-18
- 관련: [ADR-0052](0052-trigger-editor-form-overlay-kind-protocol-11.md) (트리거), [10-EDITOR](../10-EDITOR.md) 4 · 8장 (Inspector 위젯 · 콘텐츠 창),
  [02-ECS](../02-ECS.md) 9장 (리플렉션 · FieldMeta), [11-CONTENT-SCHEMA](../11-CONTENT-SCHEMA.md) 2장 (Prefab), task-registry ST-06-10

## 맥락

ST-06-10 의 완료 기준은 "스키마 → 폼 왕복". "콘텐츠" 창은 Prefab 을 JSON 글로만 고치고 (Inspector 의 리플렉션 위젯은 개체 값만),
트리거는 노드 목록 폼만 있다 — 10 8장의 [계획] "노드 그래프 캔버스 (pos 배치 · 끌어 잇기)".

## 결정

```text
1. 폼 모델     editor/services/DataForm (ImGui 없음): 컴포넌트 하나 = 섹션. 필드 = 리플렉션 (reflect 차례 · Hint · FieldMeta) +
               정규 값 (기본값 위에 원본) + set (원본에 썼다). 종류 = 켜기 · 정수 · 수 · 좌표 · 정수 좌표 · 글자 · Prefab · 행동 ·
               개체 참조 (읽기만) · 그 밖 (읽기만). opaque (render.*) · 모르는 컴포넌트는 JSON 통째 (읽기만 섹션)
2. 쓰기        setFormField = 종류 검사 · FieldMeta 범위로 자르기 · 정수 반올림 → 컴포넌트 검증 (validateJson) 을 통과해야 원본에
               (원자적). "기본값으로" = 원본에서 키를 뺀다. 컴포넌트 더하기 (빈 값 — 모두 기본) · 빼기, 엔진 관리는 거절
3. 왕복        원본 → 폼 → set 필드만 = 같은 원본 (정규 값으로 비교). 폼은 원본 JSON 을 고친다 — 검사 · 적용 (EditContent) 은 창의
               JSON 경로 그대로 (서버가 같은 검사)
4. 그래프      트리거 "그래프" 탭: 노드 상자 (범주 색) · 연결 곡선 (else 붉게). 자리 = 노드의 "pos" (편집 정보 — 실행 · 검사와 무관),
               없으면 들어오는 연결이 없는 노드에서의 가장 긴 깊이 (열 210) · 그 깊이의 차례 (행 80). 상자를 끌면 "pos" (정수),
               오른쪽 점에서 끌어 놓으면 잇기 (Shift = else), 연결 점 오른쪽 클릭 = 지우기. 잇기 규칙: 같은 노드 · 없는 노드 · 이벤트로
               들어감 · 이미 있음 · else 는 조건에서만 = 거절 (이유 표시). 도우미는 ImGui 없이 (시험)
```

## 결과

- Prefab 을 필드 위젯으로 고치고 (슬라이더 범위 · Prefab 고르기), 트리거를 그림으로 잇는다 — 둘 다 같은 JSON · 같은 적용 길.
- Rule · Behavior 의 폼, 그래프의 노드 더하기 (폼 탭에서) · 여러 개 고르기 · 확대는 [계획].

## 고른 것 · 버린 것

- 폼 전용 저장 형식 (폼 상태를 따로 둠): JSON 과 둘이 어긋난다 — 원본 JSON 하나를 고친다.
- 그래프 라이브러리 (imnodes 등): 의존을 늘린다 — 노드 수가 작아 ImDrawList 로 충분하다.
