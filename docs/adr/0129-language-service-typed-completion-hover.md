# ADR-0129. 언어 서비스의 완성 · hover — 검사기의 타입 (자리표 이름), 내장 멤버 표, 호출마다 분석 (캐시는 측정 뒤)

- 상태: **Accepted** · 날짜: 2026-11-11
- 관련: [ADR-0091](0091-script-language-service-in-sandboxscript.md) (언어 서비스는 script/lang 안), [ADR-0128](0128-text-position-contract-byte-offset-ime-area.md)
  (위치 = 바이트 offset), [27-SCRIPT-IDE](../27-SCRIPT-IDE.md) 2 · 3 · 7장, task-registry M6-T8 (조각 1)

## 맥락

언어 서비스는 "ctx." 뒤를 글로만 고르는 프로토타입이었다 (수신자 이름이 ctx 일 때만). M6-T8 은 식의 타입으로 고르는 완성 · hover 가
P0 이다. 편집 중인 글은 "m." 처럼 불완전해 그대로는 파싱되지 않고, 검사기는 메서드를 이름 비교로 풀어 (표가 없다) 내장 멤버를 나열할
곳이 없다.

## 결정

```text
1. complete(LanguageQuery {팩의 파일들 · 문서 · 바이트 offset · 팩 import}) / hover(같은 질의) — Studio 편집기 · [계획] sbx lsp 가 쓴다
2. 식 뒤 '.' 의 타입 = 커서의 접두 자리에 자리표 이름 (__sbx_complete__) 을 넣어 문장을 맞추고 검사기를 돌려, 그 Member 마디의 대상 마디
   타입 (NodeSema) 을 읽는다. 대상이 enum 이름 · Math · vec2 면 그 멤버. T | null 은 null 을 뺀 타입의 멤버 (좁힌 뒤에 쓴다). 파싱 오류가 다른
   곳에 있으면 옛 글 방식 ("ctx." — 도메인은 글의 domain: "client")
3. 멤버의 출처: 구조체 · 컴포넌트 데이터 = 검사기 타입 표, Host 멤버 (ctx · Entity …) = Host 표 (도메인은 타입이 정한다 — ServerContext ·
   ClientContext), 내장 (배열 · 문자열 · Map · Set · 컬렉션 · Math · vec2) = script/lang/MemberCatalog (이름 · 서명 · 설명). 시험이 표의 모든
   이름을 검사기가 받는지 (S406 없음) · 내장 표 (Intrinsics) 의 받는 쪽 메서드가 모두 표에 있는지 본다 — 둘이 어긋나면 실패
4. import { | } from "sandbox" = sandboxExportNames (검사기의 SDK 이름 — 값 · 타입 · 엔진 컴포넌트), "./x" = 그 모듈의 export. 이미 쓴 이름은 뺀다
5. 이름 완성은 접두가 있을 때만: 커서를 품은 함수 (커서 앞의 가장 가까운 함수 선언) 의 지역 · 매개변수 (커서 앞), 모듈 이름, 가져온 이름, 전역.
   대소문자를 가리지 않는 접두 — 정확히 맞는 것 먼저
6. hover: Ident 마디 (기호) · Member 마디 ('.' 뒤 이름 — Host · 필드 · enum · 내장), 선언 자리의 이름 (커서 앞의 가장 가까운 같은 이름 선언).
   함수는 서명 + 선언 위의 // · /** */ 주석 (Roblox 의 블록 주석 툴팁 — 27 2장)
7. 분석은 호출마다 검사기 한 번 (캐시 · Worker 없음) — 측정: Release 1,000 줄 3.8 ms · 5,000 줄 18 ms (완성), hover 3.5 · 22 ms. 편집기는
   입력 멈춤 뒤에 부른다 (27 4장의 300 ms). 파일 단위 캐시는 큰 팩 측정 뒤 [계획]
```

## 근거

```text
- 자리표: 불완전한 식을 고치는 별도 파서 (오류 회복 AST) 를 짓지 않고 검사기를 그대로 쓴다 — 타입 규칙이 하나
- 표 + 대조 시험: 검사기의 if 사슬을 표로 바꾸는 큰 고침 대신, 표가 검사기와 어긋나면 시험이 잡는다
- 캐시 없이: 측정값이 입력 멈춤 (300 ms) 안이다 — 단순함을 먼저
```

## 결과

- 얻는 것: 타입 기반 완성 (필드 · Host · 내장 · enum · Math · vec2 · 컴포넌트 데이터), import 완성, 이름 완성, hover (주석 포함), 응답 측정.
- 포기하는 것: 객체 리터럴 키 · defineSystem 키 · events 완성 [계획 v0.6 표의 줄], 시그니처 도움말 (인자 자리), 빠른 수정 (ST-06-8).
- 위험: 자리표가 이름 규칙과 부딪히는 글 (이미 그 이름을 쓴다) — 쓰지 않을 이름으로 골랐다.

## 대안

| 대안 | 기각 사유 |
|------|-----------|
| tsserver | JS 런타임 · 부분집합 · 엔진 규칙을 모른다 (ADR-0091) |
| 오류 회복 AST | 파서 · 검사기 둘 다 불완전한 마디를 다뤄야 한다 — 큰 고침 |
| 검사기의 메서드 표를 단일 출처로 고침 | 고칠 곳이 많다 (if 사슬) — 대조 시험으로 같은 보장 |
