# ADR-0184. 작업 공간 스크립트 프로파일 — 표들을 한 가상 목록으로, 첫 열 신축 · 나머지 고정 폭 (UI-R3-09 마무리)

- 상태: **Accepted** · 날짜: 2026-11-28
- 관련: [ADR-0068](0068-script-profile-injected-diagnostic-clock-serverstats-protocol-14.md) (스크립트 프로파일), [ADR-0177](0177-studio-dock-workspace-pane-hosts.md) (패널 = 화면 · 의도),
  [ADR-0183](0183-workspace-simulation-players-panels.md) (실행 · 접속자 패널)

## 맥락

진단 창 중 "스크립트 프로파일" (서버 시스템 표 · 서버 함수 표 · 엔진 시스템 단계 표 · 클라이언트 시스템 표 · 클라이언트 함수 표 — 10 열까지)
만 프로젝트 안 작업 공간에 없었다. GraphicsUI Core 의 TableView 는 뷰 하나에 열 묶음 하나 (고정 폭 · 정렬 · 거르기 · 가로 스크롤) 인데,
이 창은 열이 다른 표 다섯을 위아래로 쌓고, 어느 표가 있는지는 월드마다 다르다 (스크립트가 없으면 엔진 표만).

## 결정

1. **한 가상 목록.** 줄 종류 = 구역 머리 · 열 머리 · 줄 · 안내. 값 모델 (`ScriptProfileModel` — `makeGuiScriptProfileModel`) 은 진단 창과
   같은 원천 (`ScriptProfileInfo`) 에서 같은 열 · 같은 자릿수 (호출/초 %.1f · 연료/호출 %.0f · ms/초 %.3f · ms/호출 %.4f …) 로 만든다.
   꺼진 시스템 · 트랩이 있는 줄은 경고색.
2. **열 = 첫 열 신축 + 고정 폭.** 이름 열 (시스템 · 함수 자리) 이 남은 폭을 갖고 나머지는 76 px. 좁으면 오른쪽 열부터 잘린다 (가로 스크롤
   없음). 그래서 자리는 넓은 칸 — 출력 그룹의 테스트 뒤 탭.
3. **읽기 도구.** 줄 고르기 · ↑↓ · Ctrl / Cmd+C = 그 줄을 탭으로 (표 계산기에 붙인다). 줄 키 = 차례 — 표 모양이 같으면 스크롤 · 고른 줄이
   남고 값만 바뀐다. 바뀐 때만 목록을 다시.

## 결과

- 진단 창 다섯 (통계 · 네트워크 · 시뮬레이션 · 접속자 · 스크립트 프로파일) 이 모두 작업 공간에 있다 — UI-R3-09 Done. 개발자 창은 프로젝트 안
  작업 공간에서 더 필요 없다 (ImGui 셸에서는 그대로).
- 열 정렬 · 가로 스크롤 · 열 폭 끌기는 없다. 필요해지면 표마다 TableView 하나 (구역마다 접는 칸) 로 바꾼다 — 값 모델 (구역 · 열 머리 ·
  줄) 은 그대로 쓴다.
