# ADR-0004. 결정론은 같은 바이너리 안에서만, 시뮬레이션은 float

- 상태: **Accepted** · 날짜: 2026-10-05
- 관련: [04-DETERMINISM](../04-DETERMINISM.md), RTS ADR-0006 · RTS `core/sim/Fixed.hpp`

## 맥락

RTS는 lockstep을 위해 기기 간 bit 결정론(D6)을 목표로 두고 16.16 고정소수점(`Fixed`)으로 이행 중이었습니다.
ADR-0003으로 lockstep을 쓰지 않으므로 기기 간 결정론의 필요가 사라졌습니다.
그러나 Replay·Save/Load 검증·버그 재현·회귀 테스트에는 여전히 결정론이 필요합니다.

## 결정

```text
보장   같은 바이너리 + 같은 콘텐츠 + 같은 시작 세이브 + 같은 명령 → 같은 WorldHash
       (스레드 수·실행 속도·렌더 여부·클라이언트 수와 무관)
비보장 다른 컴파일러/OS/CPU 사이 bit 동일성
수치   시뮬레이션은 float. /fp:precise, -ffp-contract=off 를 Core 에 강제. 해시는 정수화.
```

## 근거

```text
- 16.16 고정소수점의 정수부(±32768)는 2048² 타일 월드 + 서브타일 정밀도에 빠듯하다. 32.32 는 비용이 크다.
- 고정소수점은 모든 수학(삼각함수, sqrt)을 직접 구현해야 하고, 콘텐츠 작성자가 다루기 어렵다.
- 서버 권한 구조에서 클라이언트는 계산하지 않으므로 기기 간 일치가 필요 없다.
```

## 결과

- 얻는 것: 단순한 수학, 표준 라이브러리 사용, 콘텐츠 친화적 수치.
- 포기하는 것: 서로 다른 빌드 사이 리플레이 호환 (simVersion + buildId로 구분), 미래 lockstep 가능성.
- 위험: 컴파일러 플래그 누락 → CMake 인터페이스 타깃으로 강제, D5(스레드 수 무관) CI 검사.

## 대안

| 대안              | 기각 사유                           |
|-------------------|-------------------------------------|
| Fixed 16.16 (RTS) | 범위 부족, 비용                     |
| Fixed 32.32       | 연산 비용·구현량. 필요 없음         |
| 결정론 포기       | Replay·회귀 테스트·버그 재현을 잃음 |

## 재검토 조건

클라이언트 예측이나 lockstep이 필요해질 때.
