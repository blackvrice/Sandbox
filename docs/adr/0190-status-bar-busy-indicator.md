# ADR-0190. 상태 표시줄 진행 표시 — 빌드 · 테스트가 도는 동안 "도는 중" 만, 누르면 그 패널 (UI-R2-10)

- 상태: **Accepted** · 날짜: 2026-11-28
- 관련: [ADR-0189](0189-workspace-status-bar-footer-notices-pane.md) (상태 표시줄 · 알림)

## 맥락

UI-R2-10 (상태 · 알림 · 진행) 에서 진행 표시가 남았다. 오래 걸리는 일은 빌드 (`BuildService` — 일꾼 스레드, `running()`) 와 테스트 (`TestService` —
서버 + 클라이언트 프로세스, 프로세스마다 Running · Exited · Stopped) 둘이다. 둘 다 단계 · 퍼센트를 알리지 않는다 (빌드는 검사 → 묶기 → 쓰기가
한 번의 호출, 테스트는 사람이 끝낼 때까지 돈다). ImGui 셸은 툴바 단추 글을 "빌드 중…" 으로 바꿀 뿐이다.

## 결정

1. **퍼센트를 지어내지 않는다.** 상태 표시줄의 진행 칸은 "빌드 중…" · "테스트 N 실행 중" (N = Running 인 프로세스 수) · 둘 다면 " · " 로 잇고,
   그 아래 오가는 짧은 막대 (기간 90 frame — 호스트 frame 차례라 시험에서 결정적) 로 도는 중임만 보인다. 아무것도 돌지 않으면 칸 폭 0.
2. **누르면 그 패널.** 진행 칸은 단추 — 빌드가 돌면 빌드 패널, 아니면 테스트 패널을 앞 탭으로 (ADR-0189 의 ShowPane — 작업 공간 안의 일).
3. 원천은 서비스 그대로 (`BuildService::running` — ImGui 툴바와 같은 값, `TestService::processes` 의 Running 수). 서비스에 단계 보고가 생기면
   이 칸이 막대 대신 단계를 보인다 [계획].

## 결과

- UI-R2-10 Done (상태 표시줄 · 알림 · 진행 — 헤드리스 시험. 실제 창 확인은 QA).
- 시험: `unit_client` "status bar · notices" — 두 일 · 한 일의 글, 누르면 빌드 → 테스트 패널, 다 끝나면 칸 폭 0.
