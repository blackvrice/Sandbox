# ADR-0082. v0.6 ~ v1.0 신규 기능 배치 — 신원 · 신뢰할 서버가 필요한 기능은 그 뒤에, 버전마다 핵심 목표는 그대로

- 상태: **Accepted** · 날짜: 2026-10-28
- 관련: [21-PLATFORM-FEATURES](../21-PLATFORM-FEATURES.md) 2 · 4장, [18-PLATFORM](../18-PLATFORM.md) 6장, [ADR-0078](0078-v05-creator-alpha-scope-expansion.md),
  초안 [roadmap/v0_6 ~ v1_0](../platform/roadmap/)

## 맥락

요청은 신규 기능 12 종 (게임 UI · 게임플레이 API · 리플레이 · 관전 · 다국어 · 접근성 · 플레이어 데이터 · 발견 · 추천 · 친구 · 파티 ·
등급전 · 신고 · 운영 · 제작자 분석 · 업적 · 순위표 · 자동 업데이트) 을 v0.5 ~ v1.0 에 넣되, 버전마다의 핵심 목표 (v0.6 Hub · v0.7 안전한
온라인 · v0.8 마켓 · 호스팅 · v0.9 운영 · v1.0 GA) 를 지키라는 것이다. 초기 배치 제안이 있고, 의존 · 난이도로 바꿀 수 있다.

## 결정

```text
1. 배치 = 21 4장의 표. v0.5 는 ADR-0078 의 넷 + 진단 (자동 업데이트의 일부)
2. 규칙: 플레이어마다 · 서버 밖에 남는 데이터 (영구 저장 · 순위 · 업적 · 분석) 는 계정 (v0.6) 과 신뢰할 서버 (v0.7 — 보안 전송 D-07 ·
   공식 세션) 뒤에만. 자체 호스트 서버의 결과는 그 서버 안에서만 믿고 공식 순위 · 업적에 넣지 않는다
3. 초기 제안에서 바꾼 것 (21 4장 끝): 순위표를 v0.7 (등급전) · v0.8 (업적 · 통계) 로 나눔, 신고를 v0.6 · v0.7 · v0.9 로 나눔,
   충돌 로그 · 안전 모드 · 새 버전 알림을 v0.5 로 당김 (초안 v0.5 요구 4 와 같은 일), 실행 파일을 바꾸는 자동 업데이트는 v0.9 그대로
4. 커뮤니티는 직접 만들지 않는다 — 외부 (저장소의 Discussions 등) 링크를 Hub 목록에 (v0.6). 초안 v0.6 의 "PR/Issue 를 다시 만들지
   않는다" 와 같은 태도
5. 각 버전에 들어갈 때 v0.4 · v0.5 와 같은 계획 커밋 (진입 조건 · 열린 결정 → ADR · 마일스톤 · 태스크) 을 먼저 한다 — 이 ADR 의 배치는
   그때 다시 본다 (의존이 바뀌면 고친다)
```

## 근거

```text
- 위조: 계정 없이 저장한 진행도 · 순위는 클라이언트 · 자체 서버가 마음대로 쓴다 — 나중에 다시 만들게 된다
- 의존: 친구 · 파티는 방 (v0.7), 추천 · 플레이 분석은 플레이 데이터 (v0.7 뒤), 원격 관전은 보안 전송 (v0.7)
- 일찍 가치: 충돌 로그 · 진단은 서비스 없이 v0.5 Alpha 사용자에게 바로 쓸모 — 초안 v0.5 요구와 같다
```

## 결과

- 얻는 것: 버전마다 핵심 목표를 유지하면서 신규 기능이 의존 순서대로 들어간다.
- 포기하는 것: v0.5 · v0.6 의 소셜 · 순위 기능 (데모 · Alpha 에는 없다).
- 위험: v0.7 이 무거워진다 (보안 전송 + 방 + 데이터 + 친구 + 등급전) — v0.7 계획 커밋에서 마일스톤으로 나누고, 넘치면 등급전을 v0.8 로.

## 대안

| 대안                                        | 기각 사유                                                    |
|---------------------------------------------|--------------------------------------------------------------|
| 초기 제안 그대로                             | 순위표 (v0.8) 가 등급전 (v0.7) 보다 늦다 — 등급전이 쓸모없다 |
| 플레이어 데이터를 v0.5 로컬 파일로 먼저      | 서버 API 계약 없이 만들면 v0.7 에서 다시 — v0.7 에 로컬 구현을 같은 API 로 |
| 커뮤니티 기능 직접 구현                      | 운영 부담 · 초안의 "다시 만들지 않는다" 와 어긋남             |

## 재검토 조건

각 버전의 계획 커밋, 외부 서비스 (Hub · Cloud) 를 둘 저장소 결정 (D-06) 이 날 때.
