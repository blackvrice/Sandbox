# ADR-0110. 에디터가 되돌리기 줄의 World 참여자 — 비동기 되돌리기 (Started · finish), 기다리는 동안의 기록은 미룸, 다시 하기 무르기

- 상태: **Accepted** · 날짜: 2026-11-09
- 관련: [ADR-0109](0109-document-service-unified-undo-line.md) 1 · 5 (줄 · 참여자 — 이 ADR 이 월드 참여자를 붙인다),
  [ADR-0029](0029-inspector-server-values-undo-entries.md) (월드 편집의 기록), [ADR-0108](0108-editor-services-target-command-table.md) 3,
  [10-EDITOR](../10-EDITOR.md) 6.2 · 12D, task-registry ST-06-1

## 맥락

ADR-0109 의 줄은 참여자가 바로 되돌린다고 보았다 (undoLast → true). 월드 되돌리기는 역명령을 보내고 결과를 기다린다 (Editor::replay —
idle 이 아니면 못 한다, 일부가 거절되면 그 칸을 기록에서 뺀다). 기다리는 동안 사용자는 문서를 고칠 수 있고, 앞서 보낸 월드 편집의 결과가
와서 새 칸이 생길 수도 있다. ADR-0108 3 은 서비스가 월드 명령을 보낼 때 ICommandSink 를 render 없는 헤더로 옮기자고 했다.

## 결정

```text
1. 참여자의 대답 = Done · Started · Refused. Started 면 줄은 그 칸을 "진행 중" 으로 들고 (줄 멈춤 — undo · redo 는 false), 참여자가
   끝나면 UndoService::finish(종류, ok). ok 면 칸을 반대쪽 줄로 — 되돌리기는 그 사이 새 기록이 다시 하기를 비웠으면 (epoch) 버리고, 다시
   하기는 시작할 때의 자리에 끼운다 (그 사이 기록된 칸 앞). 실패면 칸을 버린다 (에디터도 뺐다)
2. Editor 는 IUndoParticipant (private 상속 — 옮기지 · 복사하지 않는다). attachUndo(줄) 은 이미 있는 기록을 줄에 옮겨 적고 (다시 하기는
   버림), 뗄 때 · 부술 때 줄의 World 칸을 지운다. 붙어 있으면 undo · redo (Ctrl+Z · 편집 패널) 는 줄로 — 줄의 마지막 칸이 문서면 문서를
   되돌린다. canUndo · 이름표도 줄의 것
3. 줄이 에디터를 부를 때 쓸 호스트는 Editor::undo · redo(host) 를 부르는 동안만 갖는다 — 다른 곳에서 줄을 부르면 World 칸은 Refused
   (호스트 = 세션은 바뀔 수 있다). 그래서 ICommandSink 를 옮기지 않는다 (ADR-0108 3 은 필요 없어졌다 — 서비스가 명령을 보내지 않는다)
4. 되돌리기 · 다시 하기를 기다리는 동안 끝난 새 편집의 기록 (settleTxns) 은 미룬다 — 끝난 뒤 기록 (줄 · 에디터 기록의 차례가 같다).
   붙지 않은 에디터에도 같다 (옛 동작의 틈 — 기다리던 되돌리기가 새 편집이 비운 다시 하기에 들어가던 것 — 도 막는다)
5. 기다리는 되돌리기 사이에 줄이 다시 하기를 비우면 (dropRedo) 에디터도 끝난 칸을 다시 하기에 넣지 않는다. 에디터의 상한 (100) 으로
   가장 오래된 칸을 버리면 줄에서도 그 종류의 가장 오래된 칸을 버린다 (dropOldest). 월드가 바뀌면 (12D) 줄의 World 칸만 지운다
6. 앱: Application 이 줄 하나를 갖고 (에디터보다 먼저 만들고 나중에 부순다) 에디터를 붙인다. DocumentService 는 그것을 쓰는 첫 화면
   (콘텐츠 창의 팩 파일 저장 · 스크립트 편집기) 에서 같은 줄에 붙인다
```

## 근거

```text
- Started · finish: 월드 되돌리기의 결과 기다림 · 거절 처리 (ADR-0029) 를 그대로 두고 줄의 차례만 맞춘다 — 서비스로 옮기는 대규모
  리팩터 없이 (ADR-0089 4)
- 기다리는 동안 기록 미룸: 두 줄 (줄 · 에디터 더미) 의 World 칸 차례가 늘 같아야 엉뚱한 것을 되돌리지 않는다. 미루는 시간은 한 왕복
- 호스트를 부르는 동안만: 세션 포인터를 들고 있으면 세션이 바뀐 뒤 (다른 월드 · 다시 접속) 끊어진 포인터를 쓴다
```

## 결과

- 얻는 것: 월드 · 문서 편집이 섞인 하나의 Ctrl+Z (25 3장), 붙지 않은 에디터의 다시 하기 틈도 막힘.
- 비용: 줄 · 에디터에 진행 중 상태 · epoch, 에디터를 복사할 수 없다.
- 위험: 진행 중 동안 줄이 멈춘다 (한 왕복 — 끊기면 결과가 오지 않아 계속 멈춤 — 월드가 바뀌거나 (12D) 에디터를 떼면 풀린다).

## 대안

| 대안                                   | 기각 사유                                                                   |
|----------------------------------------|-----------------------------------------------------------------------------|
| 시작하자마자 칸을 옮긴다 (낙관)          | 거절되면 줄 · 에디터 더미가 어긋난다                                         |
| 월드 되돌리기를 서비스로 옮긴다           | 역명령 · IdRemap · 결과 기다림 · render 를 아는 Editor 의 대규모 리팩터        |
| 호스트를 늘 들고 있기                   | 세션이 바뀐 뒤 끊어진 포인터                                                 |

## 재검토 조건

끊김 중 진행 중 풀기 (시간 초과), 콘텐츠 창 · 스크립트 편집기를 DocumentService 로 (같은 줄), 동시 편집 (ST-07-2).
