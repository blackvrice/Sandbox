# ADR-0083. 다국어 · 접근성 기반 — 팩 문자열 표 (presentation/strings), 팩 이름공간 키 · 로케일 대체, 폰트 대체 목록, 키 다시 묶기 · UI 배율은 사용자 설정

- 상태: **Accepted** · 날짜: 2026-10-28
- 관련: [20-CREATOR-ALPHA](../20-CREATOR-ALPHA.md) 5장, [ADR-0079](0079-game-ui-runtime-declarative-documents-renderer-adapter.md), 07 (ActionMap), 11

## 맥락

게임 · 도구의 문자열은 한국어로 코드 · 콘텐츠에 박혀 있다. 폰트는 malgun.ttf (Windows) 하나, 배율은 DPI 만, 키는 팩 게임 키 (input.json)
와 기본 묶음뿐이다. v0.5 는 기반만 만들고 전체 접근성 검증은 뒤로 미루라는 요청이다.

## 결정

```text
1. 문자열 표 = 팩 presentation/strings/<로케일>.json { "<팩>.<키>": "텍스트 {0}" } (BCP 47 언어 코드). contentHash 밖 (표시 — 서버는
   키만 쓴다). 키는 팩 이름공간 (다른 팩의 키를 덮지 못한다)
2. 참조: 게임 UI "@<키>", client ctx.ui.text(key, args), 콘텐츠의 표시 이름이 "@" 로 시작하면 키. 인자 {0} {1} (수 · 문자열). 복수형 ·
   성별 규칙은 v0.6 (의존 결정 — ICU 류)
3. 대체 사슬: 사용자 로케일 → 팩에 있는 표 하나 (표가 하나면 그것) → 키 그대로 (경고 한 번). 사용자 로케일 = 클라이언트 설정 · --locale ·
   OS 로케일 순
4. 폰트 대체 목록 (설정 — 기본은 OS 의 한국어 · 라틴 · 기호 폰트): 글자가 없으면 다음 폰트, 끝까지 없으면 □ 와 경고 한 번.
   글자 늘어남은 배치가 감당 (text 의 wrap · fit — 배치 시험이 2 배 길이로 잘림 없음)
5. 키 다시 묶기: ActionMap 의 사용자 덮어쓰기 파일 (<사용자 설정>/sandbox/bindings.json — 팩 게임 키 포함), 도구 UI 의 "키" 패널 (겹침
   경고 · 되돌리기). UI 배율: 설정 0.75 ~ 2.0 — 게임 UI 의 픽셀 · 폰트 크기에 곱한다 (DPI 와 곱)
6. v0.5 밖: 에디터 · 도구 문자열 번역 (v0.9), 색각 · 대비 테마 · 화면 읽기 점검 (v1.0), 오른쪽에서 왼쪽 글자 (계획 없음 — v1.x)
```

## 근거

```text
- 팩 안 문자열: 패키지 · 잠금 · 라이선스 요약이 그대로 번역에도 닿는다. 번역만 담은 팩 (의존) 도 된다
- 이름공간 키: 설치한 패키지가 게임의 문자열을 덮어쓰지 못한다
- 사용자 설정 파일: 게임 데이터가 아니라 사람의 것 — 프로젝트 · 패키지 밖 (안전 모드가 건너뛸 수 있다 — 20 7.5)
```

## 결과

- 얻는 것: 게임마다 여러 언어, 키 · 배율 조절, 접근성 확장의 자리.
- 포기하는 것: v0.5 의 도구 번역 · 복수형 · RTL.
- 위험: Windows 밖 폰트 (검증 안 됨 — 지원 매트릭스), 번역 품질은 제작자 몫.

## 대안

| 대안                               | 기각 사유                                                         |
|------------------------------------|-------------------------------------------------------------------|
| gettext .po · CSV                  | 새 파서 · 형식 — 팩의 다른 데이터처럼 JSON 이면 검사 · 도구가 그대로 |
| 전역 키 (이름공간 없음)             | 설치한 패키지가 게임 문자열을 덮는다                               |
| 서버가 번역한 문자열을 보냄         | 대역폭 · 사람마다 다른 로케일 — 서버는 키 · 인자만                  |

## 재검토 조건

복수형 · 성별이 필요한 언어를 지원할 때, 도구 번역 (v0.9), 접근성 점검 (v1.0).
