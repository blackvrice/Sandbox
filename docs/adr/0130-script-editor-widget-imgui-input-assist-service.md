# ADR-0130. 스크립트 편집기 위젯 — ImGui 여러 줄 입력 + 콜백, 정하는 일은 ScriptAssist 서비스, 진단은 입력 멈춤 300 ms 뒤 UI 스레드

- 상태: **Accepted** · 날짜: 2026-11-11
- 관련: [ADR-0129](0129-language-service-typed-completion-hover.md) (언어 서비스 complete · hover), [ADR-0128](0128-text-position-contract-byte-offset-ime-area.md)
  (바이트 offset · IME), [ADR-0066](0066-script-overlay-kind-recompile-same-components-protocol-13.md) (스크립트 오버레이), [ADR-0108](0108-editor-services-target-command-table.md) (editor/services 는 UI 를
  모른다), [27-SCRIPT-IDE](../27-SCRIPT-IDE.md) 3 · 4 · 7장, task-registry M6-T8 (조각 2)

## 맥락

언어 서비스 (조각 1) 를 Studio "콘텐츠" 창의 스크립트 칸에 붙여야 한다 — 자동 완성 팝업, hover, 오류 밑줄, 입력 멈춤 300 ms 뒤 진단 (27 4장).
칸은 ImGui 여러 줄 입력 (InputTextMultiline) 이다. ImGui 의 입력 칸은 글 배치 · 스크롤 · 그리기를 안에서 하고, 팝업이 쓸 키 (위아래 · Enter ·
Tab) 를 먼저 먹으며, Esc 에는 활성화 뒤 고친 것을 **모두 되돌린다** (편집기에서는 사고다).

## 결정

```text
1. 위젯 = ImGui InputTextMultiline 그대로 + 콜백 (CallbackAlways · CallbackCharFilter · CallbackResize). 자체 글 편집기를 짓지 않는다 —
   IME (확정 글자만 · 조합 창 자리 — NG-05) · 되돌리기 · 선택 · 클립보드를 ImGui 가 이미 한다
2. 정하는 일은 editor/services/ScriptAssist (UI 를 모른다 — 시험이 ImGui 없이 본다): 작업 공간 · 진단 → 밑줄 범위 · 입력 멈춤 · 완성 세션 ·
   hover 기억. 위젯 (editor/ui/ScriptEditor) 은 그리기 · 키만
3. 작업 공간 = 편집 중인 파일의 팩 scripts/*.ts (오버레이 소스가 있으면 그것 — 같은 경로는 바꾸고 없으면 더한다) + 편집 중인 글 + 의존 팩
   (이어지는 의존까지, "@<팩>/…") — 콘텐츠 로더의 compileScripts 와 같은 입력이라 같은 진단 (시험이 [검사] 결과와 코드 · 줄:열을 맞춘다)
4. 진단은 입력이 300 ms 멈춘 뒤 UI 스레드에서 검사기 한 번 (편집 번호 — 그사이 고쳤으면 결과를 버린다). Worker 는 쓰지 않는다 — 측정
   (Release 5,000 줄 21 ms) 이 한 번의 멈춤이고 타자 중에는 돌지 않는다. 밑줄 = 진단 자리부터 그 이름 끝 (이름이 아니면 글자 하나, 줄 끝 ·
   글 끝이면 앞 글자 — 진단에 길이가 없다)
5. 완성: '.' (글자 거르기 콜백) · Ctrl+Space 에 complete 를 한 번 묻고, 계속 치면 그 후보를 접두로 다시 거른다 (글자마다 검사기를 돌리지
   않는다 — complete 와 같은 거르기 · 차례, filterCompletions). 접두가 처음 물은 접두보다 짧아지면 다시 묻고, 이름을 벗어나면 닫는다
6. 키: 팝업이 열려 있으면 Enter · Tab 은 글자 거르기 콜백이 버리고 (줄 · 탭이 들어가지 않는다) 그 프레임의 Always 콜백이 후보를 넣는다
   (DeleteChars · InsertChars — 입력 칸의 되돌리기에 남는다). 위아래는 입력 칸이 옮긴 커서를 콜백이 되돌린다. Esc 는 키 경로
   (Shortcut RouteFocused | RouteOverActive) 로 입력 칸보다 먼저 받아 팝업만 닫는다 — ImGui 의 "Esc = 고친 것 모두 되돌리기" 를 막는다
   (되돌리기는 Ctrl+Z). 붙여넣기는 팝업을 먼저 닫는다 (붙인 줄바꿈을 넣기로 먹지 않게)
7. 스크롤 · 그리기: 입력 칸을 글 크기로 키우고 바깥 자식 창이 스크롤한다 — 줄 번호 · 진단 점 · 밑줄을 같은 좌표로 그린다. 입력 칸 바탕을
   투명으로 두고 밑줄을 그 아래 (바깥 창 그리기 목록) 에 먼저 그린다 (자식 창은 부모 뒤에 그려진다). 커서가 움직이면 바깥 창을 스크롤한다.
   글 배치는 ImGui 입력 칸과 같은 측정 ('\n' 만 줄을 나눈다 · ImFont::CalcTextSizeA), 줄 시작 표 (글이 바뀔 때만) 로 자리 → 줄은 이분 탐색.
   밑줄은 보이는 줄만 (진단이 많은 큰 파일의 정점 수)
8. 바깥에서 글이 바뀌면 (다른 파일 · 버리기 · 서버 값) 진단 · 팝업 · hover 를 지우고 곧 분석, 입력 칸 id 를 바꾼다 — 활성 입력 칸은 제
   버퍼로 바깥 변경을 덮기 때문 (커서 자리는 이어서)
9. hover: 마우스를 0.35 초 멈추면 그 자리의 진단 (밑줄 안이면) · 언어 서비스 hover. (편집 번호, 자리) 가 같으면 다시 묻지 않는다.
   팝업이 열려 있으면 hover 는 없다 (툴팁 하나)
```

## 근거

```text
- ImGui 입력 칸 재사용: IME · 되돌리기 · 선택 · 클립보드를 다시 짓는 비용 (그리고 그 시험) 이 크다. 콜백 · 키 경로로 필요한 것을 모두 얻었다
- 서비스 분리: 정하는 일 (거르기 · 다시 묻기 · 늦은 결과 · 밑줄 범위) 을 ImGui 없이 시험한다 — ADR-0108 의 분리 그대로
- UI 스레드 분석: 측정이 300 ms 멈춤 · 프레임 예산에 비해 작고, Worker 는 문서 버전 · 결과 전달 · 취소를 더한다 (L3 의 "늦은 결과는 버린다"
  는 편집 번호로 이미 지킨다)
- Esc 가로채기: 편집기에서 키 하나로 고친 것을 모두 잃는 것은 데이터 손실이다 (M6-T7 자동 저장과 같은 이유)
```

## 결과

- 얻는 것: 줄 번호 · 진단 점 · 물결 밑줄 (오류 · 경고 색 — 테마 토큰), 실시간 진단 목록 (누르면 그 자리로 — G7 의 "오류 줄로 이동" 편집기 쪽),
  '.' · Ctrl+Space 완성 팝업 (종류 · 서명 · 설명), hover (진단 · 서명 · 주석), 측정 (Release 5,000 줄 · 밑줄 1,000: 분석 21 ms, 쉬는 프레임
  0.24 ms, 타자 프레임 0.56 ms — test_script_assist).
- 포기하는 것: 구문 색 (ImGui 입력 칸은 글자마다 색을 받지 않는다 — 자체 그리기 층이 필요, [계획]), 마우스로 팝업 고르기 (팝업은 툴팁 —
  키만, [계획]), 글자를 칠 때 저절로 여는 이름 완성 ('.' · Ctrl+Space 만), 줄 바꿈 (가로 스크롤).
- 위험: Debug 빌드는 분석이 약 30 배 (5,000 줄 0.8 초 — 입력이 멈출 때 한 번 끊긴다). 큰 팩 · Debug 에서 문제가 되면 Worker (재검토 조건).
  ImGui 판 올림이 콜백 · 키 경로 (RouteOverActive) 의 동작을 바꿀 수 있다 — 위젯 시험 (키 주입) 이 잡는다.

## 대안

| 대안 | 기각 사유 |
|------|-----------|
| 자체 글 편집기 위젯 (ImGuiColorTextEdit 류) | 구문 색은 얻지만 IME (NG-05 계약) · 되돌리기 · UTF-8 바이트 offset 을 다시 맞춰야 한다 — 외부 의존 · 시험이 크다. 구문 색이 필요해지면 그리기 층부터 |
| 분석 Worker 스레드 | 지금 측정으로는 이득보다 복잡도 (문서 사본 · 버전 · 취소) — 재검토 조건 |
| 글자마다 complete 다시 묻기 | Debug 에서 글자마다 100 ms 대 — 처음 물은 후보를 거르면 같은 결과 |
| Esc 를 ImGui 기본 (되돌리기) 으로 둠 | 키 하나로 편집을 모두 잃는다 |

## 재검토 조건

큰 팩 (50 파일) · Debug 에서 멈춤이 눈에 띌 때 (파일 단위 캐시 · Worker), 구문 색 요구 (그리기 층), sbx lsp (v0.21 — 같은 서비스), 마우스 팝업 ·
시그니처 도움말 (ST-06-8).
