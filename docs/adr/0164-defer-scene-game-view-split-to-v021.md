## 맥락

ADR-0123 은 ST-06-11 을 "v0.12 시작 때 다른 P2 · P3 와 함께 필요성을 판정한다" 고 했다. 재검토 조건 셋을 v0.12 의 끝 (다른 v0.12
태스크가 모두 Done) 에서 본다:

```text
1. 게임 카메라 · 화면 비율이 필요한 템플릿 · 제작자 요청 — 없다. v0.12 의 템플릿 (타일맵 · 애니메이션 · Prefab 변형) 은 같은 뷰로 된다
   (카메라는 game.camera_start · 모드 띠 — ADR-0118)
2. 플랫폼 창 층의 다중 창 — 없다 (Win32 · X11 · Cocoa 모두 창 하나, 07)
3. 렌더러의 뷰 둘 (뷰마다 업로드 링 · 타임스탬프 · 오프스크린 RenderTarget 을 ImGui 텍스처로) — 세 백엔드 (D3D12 · Vulkan · Metal)
   를 바꾸고, 완료 기준이 창 QA 라 자동 검증이 없다. 창 QA 자체가 밀려 있다 (MANUAL-QA — v0.8 ~ v0.11 의 창 줄)
```

## 결정

```text
1. ST-06-11 의 목표 버전을 v0.12 → v0.21 (팀 · 협업 · 플러그인 — Studio 의 다중 창 · 레이아웃 공유와 같은 자리). P3 그대로
2. 다시 할 때의 차례는 ADR-0123 2 그대로 — (a) 게임 카메라 콘텐츠 정의 → (b) 오프스크린 Game 뷰 → (c) 떼어 낸 창
3. v0.12 의 남은 일 = NG-20 통합 시험 · 창 QA · 릴리스 준비
```

## 결과

- v0.12 범위가 닫힌다 (P3 하나 빼고 구현 태스크 Done). 렌더러 · 플랫폼 변경은 다중 창 요구와 같이 한 번에.
- 포기하는 것: v0.12 의 Game 뷰 · 다중 모니터 (같은 뷰 + 모드 띠로 대신).
