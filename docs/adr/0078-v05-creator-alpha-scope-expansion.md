## 맥락

초안의 v0.5 는 "첫 외부 제작자 릴리스" — 템플릿 · 패키지 UX · 스크립트 개선 · 오류 보고 · 배포 채널 · 피드백과 완료 기준 넷 (A 제작 ·
공유, B 실행 · 진단, 노코드 · 스크립트 미니게임 E2E, 치명 결함이면 배포 중지). v0.4 까지의 코드를 대조하면 (21 1장) 게임을 "게임처럼"
만들 기반이 빠져 있다: 게임 UI 가 없고 (ImGui 도구 패널 · 스크립트 label 뿐), 스크립트가 개체를 만들거나 엔진 컴포넌트를 볼 수 없고
(v0.3 에서 미룸), 문제를 다시 볼 뷰어 · 다국어 · 키 설정이 없다. 요청은 v0.5 를 이 네 가지로 넓히되 초안의 목표 · 완료 기준을 줄이지
말라는 것이다.

## 결정

```text
1. 초안의 요구 R1~R6 · 완료 기준 C1~C4 를 그대로 둔다 (20 1.1). 확장 X1~X5 를 더한다 (20 1.2): 게임 UI (ADR-0079), 게임플레이 API
   (ADR-0080), 리플레이 뷰어 (로컬 — 원격 관전 v0.7), 다국어 · 접근성 기반 (ADR-0083), 스크립트 실행 경계 · 함수별 프로파일 (ADR-0081)
2. 넣지 않는 것: 플레이어 데이터 · 친구 · 파티 · 등급전 · 업적 · 추천 · 분석 · 원격 관전 · 자동 업데이트 (실행 파일 교체) · JIT/AOT ·
   게임 UI 시각 편집 · 애니메이션 · 서명 (ADR-0082 배치)
3. 템플릿 3종 = 노코드 미니게임 (+ HUD) · 스크립트 보드게임 (오목) · 생존. 초안의 "RTS" 는 유닛 명령 모델 (D-11 — v0.2 는 행동부터) 이
   없어 바꾼다 (보드게임이 스크립트 규칙 · UI · 세이브를 모두 보인다)
4. 공식 데모를 더한다: samples/omok (스크립트 규칙 · UI · 세이브 — C3 의 스크립트 쪽), samples/hud_guard (노코드 + HUD — C3 의 노코드
   쪽). 기존 rabbit_guard · mana_regen · stash 는 그대로 회귀 시험
5. 순서 = 의존 그래프 (20 10장): M1 진단 · 채널 ∥ M2 게임플레이 API → M3 게임 UI → M4 다국어 → M6 제작 UX → M7 데모 · 릴리스,
   M5 리플레이 뷰어는 M1 뒤 아무 때나
6. 늦으면 미루는 순서 (v0.6 으로): 다국어 폰트 대체 · 늘어남 (M4-T2) → 리플레이 체크포인트 (M5-T2 의 일부) → UI 에디터 편집 (M3-T7 —
   미리보기는 남긴다) → 소리 출력 (D-14). 완료 기준 C1~C4 · 데모 둘 · X1 의 기본 · X2 는 미루지 않는다
7. 지원 매트릭스: Windows 10 · 11 x64 + D3D12 만 "지원". Linux · macOS 는 "검증 안 됨" (빌드 경로만) — 수치는 측정한 것만 (20 7.8)
```

## 근거

```text
- 넷 다 C3 (노코드 · 스크립트 미니게임 E2E) 를 "게임" 으로 만족시키는 최소: UI 없이는 점수 · 차례를 플레이어가 볼 수 없고, 구조 변경
  없이는 스크립트 보드게임이 돌을 놓지 못하며, 뷰어 · 진단 없이는 C2 의 "원인 진단" 이 로그 읽기다
- 초안을 줄이지 않는다는 요청 — 확장은 더하기만
- 서비스가 필요한 기능 (데이터 · 친구 · 순위 · 분석) 은 계정 · 보안 전송 (v0.6 · v0.7) 없이 위조를 막을 수 없다
```

## 결과

- 얻는 것: v0.5 데모가 실제 게임 (차례 · 승패 · HUD · 버튼) 이고, 제작자가 만든 규칙 · UI 를 다른 PC 의 사용자가 실행 · 진단한다.
- 포기하는 것: v0.5 일정 (마일스톤 일곱 — 미룰 순서를 정해 둔다), 초안의 RTS 템플릿.
- 위험: 범위 과다 · ImGui 백엔드의 품질 · 구조 변경의 결정성 (20 14장).

## 대안

| 대안                                         | 기각 사유                                                           |
|----------------------------------------------|---------------------------------------------------------------------|
| 초안 그대로 (확장 없음)                       | C3 의 데모가 디버그 패널 · 콘솔로만 보이는 "게임" — Alpha 사용자가 만들 게임이 없다 |
| 12 기능 중 더 많이 (데이터 · 순위) 를 v0.5 에 | 계정 · 보안 전송이 없어 위조를 막을 수 없다 — 다시 만들게 된다      |
| RTS 템플릿 유지                              | 유닛 명령 모델 결정 (D-11 다음 단계) 이 먼저다 — v0.6 이후 후보       |

## 재검토 조건

마일스톤 M3 끝에 ImGui 백엔드 측정 (20 12.3) 이 나쁠 때 (백엔드 결정), v0.5 일정이 크게 밀려 미룰 순서를 넘어설 때.
