# Sandbox 0.7.0 — 게임 UI Runtime · 다국어 기반 (2026-11-09)

> **이력 문서** (바꾸지 않는다 — 다음 버전은 새 파일). 버전 · 태스크의 정본은 [roadmap/](../roadmap/README.md), 출시 기준은
> [release-gates](../roadmap/release-gates.md) 2장 v0.7 행, 설계는 [20-CREATOR-ALPHA](../20-CREATOR-ALPHA.md) 2 · 5장, 결정은
> [ADR-0079](../adr/0079-game-ui-runtime-declarative-documents-renderer-adapter.md) · [ADR-0083](../adr/0083-i18n-accessibility-foundation.md) ·
> ADR-0101 ~ 0107. 제품 버전 = CMake `project VERSION 0.7.0`.

## 1. 한 줄

게임이 **자기 HUD · 메뉴** 를 띄운다: 팩 presentation/ui 의 선언 문서 (패널 · 글자 · 버튼 · 진행 막대 · 목록 · 입력 컨트롤) 를 검사하고
(U1 ~ U8), 헤드리스로 같은 정수 사각형에 배치하고, ImGui 배경 그리기 목록으로 그린다. 값은 바인딩 (var · session · component) 으로 읽고,
버튼 · 컨트롤은 서버가 판정하는 신호 · 행동을 보낸다 (UI 가 서버 상태를 바로 바꾸지 않는다). 글은 팩 문자열 표 ("@<키>") 의 사용자
로케일로, 없는 글자는 폰트 사슬 · □ 로, 키는 다시 묶고, UI 배율은 사용자 설정이다. checkbox · toggle · slider · 글자 칸 (한글 IME 확정 글자)
· dropdown · tabs · scroll 을 마우스 · 키보드 · 게임패드 (Windows) 로 쓴다.

## 6. 알려진 문제

```text
- 창 눈 확인을 하지 못했다: overflow · 키 패널 · 배율 · 입력 컨트롤 · 글자 칸 (한글 IME) · dropdown · tabs · scroll · 실제 게임패드는
  헤드리스 시험 (배치 · 그리기 명령 · 앱 E2E) 만 — docs/qa/MANUAL-QA.md 의 v0.7 [ ] 줄
- IME 조합 창은 OS · 입력기의 자리 (캐럿에 맞추지 않는다). 글자 칸의 글은 서버에 가지 않는다 (신호는 길이)
- 게임패드: Windows XInput 만 (Linux · macOS 는 패드 없음), 실제 패드로 확인하지 못했다. 패드는 게임 키가 아니다 (게임 UI 만)
- client 스크립트 오버레이의 컴파일 오류가 조용하다 (알려진 뒤 일 — v0.10 RT-06-7 쪽)
- 0.6 에서 이어진 것: 실기 QA 없음 (Export Profile "미검증" 경고), 스냅숏 만들기 클라 16 · 50k = 37 ms, 소리 출력 없음
```
