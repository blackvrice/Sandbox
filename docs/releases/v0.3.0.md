# Sandbox 0.3.0 — SandboxScript (2026-10-27)

> **이력 문서** (바꾸지 않는다 — 다음 버전은 새 파일). v0.3 의 계획 · 마일스톤은 [18-PLATFORM](../18-PLATFORM.md) 6.2,
> 언어 · VM · Host API 의 규범은 [19-SANDBOXSCRIPT](../19-SANDBOXSCRIPT.md), 요구사항의 출처는
> [플랫폼 설계 초안 roadmap/v0_3](../platform/roadmap/v0_3_SANDBOXSCRIPT.md). 제품 버전 = CMake `project VERSION 0.3.0`.

## 1. 한 줄

TypeScript 의 엄격한 부분집합 (SandboxScript) 으로 컴포넌트 · 서버 시스템 · 클라이언트 표시를 쓰고, 자체 컴파일러 → 검증된 바이트코드
(.sbc) → 예산 있는 VM 으로 돌린다. 스크립트는 세이브 · 복제 · Inspector · 해시가 내장 컴포넌트와 같고, 게임을 멈추지 않고 고치며,
나쁜 스크립트는 그 시스템만 꺼지고 결과에 흔적을 남기지 않는다. 데모: [samples/mana_regen](../../samples/mana_regen/README.md) "마나 재생".

## 6. 알려진 문제 · 열린 검증

```text
- Windows 의 CTest 는 chcp 65001 (UTF-8 콘솔) 뒤에 돌린다 (v0.2 와 같다)
- render_tests_warp: 이 개발 PC 에서 D3D12 Debug Layer 의 배리어 메시지로 "render tests OK" 가 나오지 않는다 (v0.2 와 같다 — v0.3 은
  render 를 건드리지 않았다)
- samples/mana_regen 의 기대 해시는 MSVC 키만 기록했다 — 다른 툴체인에서는 해시를 보지 않는다 (서버 = 로컬 비교는 한다)
- 스크립트 비용: 10k 개체를 매 틱 읽고 쓰면 약 9.9 ms/틱 (Release — 14 7.13). 게임 스크립트는 intervalTicks 로 주기를 둔다
- 스크립트 편집 창 · 프로파일 패널 · 개체 위 글자를 창에서 눈으로 본 확인은 없다 — 그리기는 헤드리스 ImGui 시험이 부른다 (실기 QA 로)
- v0.1 의 열린 항목 그대로 (18 1.1): Windows · Linux · macOS 실기 QA, 50k 판정, GitHub Actions 결과. Linux · macOS 에서 v0.3 빌드 ·
  시험은 이 환경에서 돌리지 않았다
- 네트워크는 LAN · 신뢰 환경 전용 (R6 — 암호화 없음). 스크립트 소스는 오버레이로 모두에게 복제된다
```
