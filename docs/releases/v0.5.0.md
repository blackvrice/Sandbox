# Sandbox 0.5.0 — Technical Alpha (2026-11-03)

> **이력 문서** (바꾸지 않는다 — 다음 버전은 새 파일). v0.5 의 계획은 [20-CREATOR-ALPHA](../20-CREATOR-ALPHA.md) (설계 · 카드),
> 범위를 Technical Alpha 로 줄인 결정은 [ADR-0096](../adr/0096-roadmap-versioning-small-milestones.md), 버전 · 태스크의 정본은
> [roadmap/](../roadmap/README.md), 출시 기준은 [release-gates](../roadmap/release-gates.md) 2장 v0.5 행. 제품 버전 = CMake `project VERSION 0.5.0`.

## 1. 한 줄

엔진 핵심을 내부 개발자용 Technical Alpha 로 낸다. 스크립트가 엔진 컴포넌트를 읽고 쓰고 · 개체를 만들고 지우고 · 무작위 · 주변 질의 ·
플레이어 · 행동 · 신호 · client 입력을 쓰며 (Runtime v2 계약 동결 — 콜백 표 · capability), 표준 라이브러리 (배열 · Map · Set · 큐 · 힙 ·
Graph · 알고리즘 · vec2 · 엔진 질의) 가 들어갔다. 충돌하면 보고 묶음이 남고 sbx doctor 가 문장으로 진단한다. **CLI 로 만든 게임 패키지 하나를
배포 묶음 엔진만 가진 다른 환경에서 열면 같은 WorldHash 가 나온다** (CTest tech_alpha_e2e). 처음 계획한 "Creator Alpha" (외부 제작자가 Studio
만으로) 는 Closed Creator Alpha (v0.13) 로 옮겼다 — 5장.

## 6. 알려진 문제

```text
- 실기 QA 없음: Windows · Linux 창 · GPU · 입력은 CI 헤드리스 · Wine · WARP 로만 (v0.1 부터 — v0.23 RH-23-7). macOS MANUAL-QA 14B · 14C 남음
- 소리가 나지 않는다: client.playSound 는 이벤트만 (ADR-0095)
- 스냅숏 만들기 클라 16 · 50k = 37 ms — 3 ms 목표 못 맞춤 (14 7.11, v0.22 RH-22-6 에서 재판정)
- 0.4 와 0.5 는 서로 접속하지 않는다 (프로토콜 15)
- 스크립트 오류는 줄 번호 없이 함수 · 단계로만 (줄 표는 v0.9 M6-T4)
```
