> **이력 문서** (바꾸지 않는다 — 다음 버전은 새 파일). 버전 · 태스크의 정본은 [roadmap/](../roadmap/README.md), 출시 기준은

> 제품 버전 = CMake `project VERSION 0.6.0`.

## 1. 한 줄

게임이 **자기 PNG** 를 싣는다: 프로젝트 assets/ 의 파일마다 경로와 따로인 안정 id (.meta), 팩 materials.json 이 `asset:<id>` 로 부르고,
게임 패키지 (.sbpkg 형식 3) 에 실려 다른 폴더 · 빈 캐시의 클라이언트가 그린다. 같은 프로젝트는 같은 패키지 digest 이고 (빌드 스냅숏 —
검사한 것 = 실은 것), 에셋 id · 경로 충돌은 조용히 넘기지 않는다. 시뮬레이션 해시와 표시 digest 가 갈라져 그림만 다른 클라이언트도
접속하고, 게임 버전이 바뀐 세이브는 매니페스트 migrations 와 스크립트 onMigrate 로 옮긴다 (더 새 게임의 세이브는 거절).

## 6. 알려진 문제

```text
- 실기 QA 없음: Windows · Linux 창 · GPU 는 CI 헤드리스 · Wine · WARP · lavapipe 로만 — Export Profile 의 모든 대상이 "미검증" 경고를 낸다
  (verifiedTargets 가 비었다 — docs/qa/MANUAL-QA.md 에 통과 기록이 생기면 더한다)
- 0.5 와 0.6 은 서로 접속하지 않는다 (프로토콜 16). 0.5 엔진은 에셋을 실은 패키지 (형식 3) · migrations 를 쓴 매니페스트를 열지 않는다
- 패키지는 assets/ 의 모든 에셋을 싣는다 — 그룹은 보고만 (RT-08-4)
- 서버 시작 (--world <프로젝트>) 의 시작 월드는 마이그레이션하지 않는다 (프로젝트의 것) — 세이브 불러오기만
- 스냅숏 만들기 클라 16 · 50k = 37 ms (0.5 그대로 — v0.22 RH-22-6), 소리 출력 없음 (ADR-0095)
```
