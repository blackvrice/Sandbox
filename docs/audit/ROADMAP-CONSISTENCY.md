## 3. 검사기가 정말 잡는지 (음성 시험)

저장소를 임시 폴더로 복사하고 releases.md 에 없는 태스크 (NG 99 번) · Done 태스크와 [계획] 을 같은 줄에 (M2 T6) · 없는 ADR (9999 번) · 없는
파일로 가는 링크를 한 줄로 더하고, 등록부의 NG-15 목표를 버전 목록에 없는 값 (0.99) 으로 바꿔 돌렸다 → L · A · T · S · V 다섯 종류가 모두
걸리고 종료 코드 1. (이 문단은 검사기에 걸리지 않도록 그 문자열을 그대로 적지 않는다.) (복사본에 samples/ 를 넣지
않아 그쪽 링크 L 이 더 걸린 것은 시험 설정 탓 — 저장소에서는 0 건.)

## 4. 검사가 보지 않는 것 (한계)

```text
- 태스크의 의미 (선행이 실제로 먼저 끝나는지 · 완료 기준이 시험 이름과 맞는지) — 등록부를 고칠 때 사람이 본다
- 옛 문서의 "[계획 v0.6]" 같은 옛 버전 표기 — 고치지 않고 versioning 4장 변환표로 읽기로 했다 (ADR-0096 결과)
- v0.1 ~ v0.4 의 태스크 ID 가 v0.5 ID 와 같은 모양일 때 (예: 18 7장 "M2-T1 ✅") — 앞에 "v0.N" 이 없으면 v0.5 의 것으로 본다. 걸리면 KNOWN
- 문서 밖 (코드 주석) 의 태스크 ID
```
