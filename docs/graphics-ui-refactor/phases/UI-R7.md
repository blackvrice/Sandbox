## 미리 정해 둔 원칙

- 게임 제작자의 UI (ui/ — 팩 · 프로젝트 데이터) 와 Studio UI 를 분리한다. ui/ 의 문서 · 배치 · 바인딩 · 문자열은 그대로 두고, 그리기 ·
  입력 어댑터만 바꾼다 (지금 `GameUiImGui` 자리).
- 사용자 제작 UI 는 Native API · 임의 파일 · 네트워크 · 임의 C++ · 제한 없는 GPU 할당을 쓰지 못한다. 한도: 노드 수 · 텍스처 메모리 ·
  이벤트 수 · 바인딩 평가량 (R7-02 설계 — 지금 ui/ 의 문서 크기 한도 U1 ~ U8 를 확장).
- 서버는 UI 렌더러를 로드하지 않는다 (지금처럼 — CMake 검사).
- 멀티플레이: UI 상태는 클라이언트 표시 쪽 — 서버 권위 상태는 바인딩으로 읽기만 (R7-05).
